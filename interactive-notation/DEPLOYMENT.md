# SJMTC Interactive Notation — Team Pilot

This package contains a landing page and standalone HTML viewers for Songs 30 and 150. No existing website files have been modified.

## Recommended Google Sites workflow

1. Host the **contents** of this folder on a static HTTPS host (e.g. a dedicated GitHub Pages testing repository or a `choir-test/` directory in an existing GitHub Pages deployment). Keep the song-30 and song-150 folders alongside index.html.
2. Open the hosted `index.html` URL and test both links on desktop and mobile.
3. In Google Sites, add a new page titled `Interactive Notation – Beta Testing` or add a link under Related Links. Use **Insert > Button** to point to the hosted landing page URL. You can also try **Insert > Embed > By URL**, but some hosts and Google Sites embed restrictions may prevent iframe embedding. A regular link is the most reliable.
4. Publish the Google Site. Avoid placing this under the main music library until the team has reviewed it.

Important: uploading raw HTML to Google Drive or attaching the ZIP to Google Sites does not provide a reliable public HTML hosting URL. No Google Site or GitHub repository has been changed by this package.
